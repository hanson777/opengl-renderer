# OpenGL Renderer

This repository hosts a renderer I'm building as I work through learnopengl.com.

My long term goals for this project are to implement advanced rendering and lighting techniques, such as:

- Deferred Rendering
- Global Illumination
- Physically Based Rendering (PBR)
- SSAO
- Shadow Mapping
- Volumetric Light Scattering (god rays)

Current Features

- Model loading via `tinyobjloader`
- Phong shading
- Normal mapping
- Free-fly camera

More to come!
